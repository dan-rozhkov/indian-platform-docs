# Gap-анализ: PM

**Автор:** Senior PM
**Дата:** 2026-03-29

## Критичные гэпы (блокируют старт)

1. **Статусная машина заявки и кандидата** — нет единой state machine. Без неё невозможно проектировать бэкенд и UI переходов.
2. **ER-диаграмма / Data Model** — 13 микросервисов без модели данных. Риск дублирования сущностей и несогласованности.
3. **RBAC-матрица** — суброли описаны текстом, нет формальной таблицы. Без неё нельзя настроить авторизацию.

## Важные гэпы (до первого спринта)

4. **Приоритизация внутри MVP** — 29 сценариев не ранжированы
5. **API-контракты** — ни одного OpenAPI/AsyncAPI
6. **Нефункциональные требования** — не специфицированы (RPS, SLA, 152-ФЗ)
7. **Бизнес-правила и валидации** — не структурированы
8. **User Stories с acceptance criteria** — сценарии слишком высокоуровневые
9. **Метрики успеха / KPI** — отсутствуют
10. **Реестр рисков** — не зафиксирован
11. **Структура брифа** — нет списка полей
