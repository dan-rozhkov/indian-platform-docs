- [x] Список заявок с фильтрацией и счётчиками
- [x] Создание заявки через форму

- [x] Прогресс подбора: N из M кандидатов одобрено
- [ ] Контекстные подсказки GigaChat по правильному заполнению заявки (?)

- [x] Список кандидатов по заявке
- [x] Просмотр анкеты кандидата (на русском, с автопереводом)
- [ ] Просмотр документов с прогресс-баром загрузки

- [x] Одобрение кандидата

- [x] Статус квотной заявки + ключевые даты
- [x] Хранение документов квотного дела
- [ ] Контекстные подсказки GigaChat по шагам и процессу квотирования

**GigaChat-ассистент (клиент)**
- [x] Плавающая кнопка ассистента для контекстной помощи

**Заявки (РФ-партнёр)**

- [x] Принятие заявки в работу (кнопка «Взял в работу»)

**Кандидаты (РФ-партнёр)**
