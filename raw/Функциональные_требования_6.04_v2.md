# Функциональные требования платформы

## Типы приоритетов

| Приоритет | Описание |
|-----------|----------|
| **base** | Базовые функции, без которых платформа не может работать в принципе: авторизация пользователей, создание организаций и заявок, просмотр данных, базовое управление кандидатами |
| **key feature** | Ключевые функции, необходимые для полноценной работы продукта |
| **killer feature** | Дифференцирующие функции, критически важные для ценностного предложения |
| **nice to have** | Желательные функции, некритичные для запуска |
