# Микросервисы

Бэкенд платформы состоит из 13 микросервисов. Общая архитектура — [[Техническая архитектура]].

## Перечень сервисов

| # | Сервис | Назначение |
|---|--------|------------|
| 1 | Сервис заявок | Процессы работы с заявками |
| 2 | Сервис компаний | Работа с компаниями, настройки (участники, роли, уведомления) |
| 3 | Сервис кандидатов | Процессы работы с кандидатами |
| 4 | Сервис вакансий | Вакансии и шаблоны |
| 5 | Сервис словарей | Ведение справочников |
| 6 | Сервис документов | Документы, шаблоны, подписи |
| 7 | Сервис логистики | Отслеживание и учёт логистических данных |
| 8 | Сервис отчётности | Построение отчётов по требованию |
| 9 | Сервис мониторинга | Мониторинг истекающих SLA |
| 10 | Сервис авторизации | СберБизнес ID, собственный ЛК, ролевая модель |
| 11 | Сервис уведомлений | Email-нотификации |
| 12 | Сервис тарифов | Альбом тарифов |
| 13 | AI-processing (будущий) | OCR, парсинг, перевод, генерация документов |

## Открытые вопросы

> [!warning] Контракты API не определены
> По итогам PM-анализа выявлен гэп: API-контракты между сервисами отсутствуют. Необходимо принять решения по протоколам взаимодействия (REST / gRPC / event-driven).

Интеграции с внешними системами — [[Интеграции]].
