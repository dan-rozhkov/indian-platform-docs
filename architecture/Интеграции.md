# Интеграции

Интеграционный слой платформы включает 30 адаптеров к внешним системам. Общая архитектура — [[Техническая архитектура]], бэкенд — [[Микросервисы]].

## Известные интеграции

| Система | Функции |
|---------|---------|
| **SberCRM** | Получение заявок, обмен статусами, досыл документов |
| **МЗП** (зарплатные проекты) | Формирование ЗП-проекта, обмен документами и статусами |
| **СберСтрахование** | Запросы, документы, статусы |
| **СберЗдоровье** | Запросы, документы, статусы |
| **Госсистемы** (МВД, Минтруд) | Заявки, документы, статусы (целевой контур) |
| **Sber Business ID** | OAuth-регистрация юридических лиц |
| **SberIndia ID** | OAuth для индийской стороны (новая интеграция, отсутствует в исходной документации) |
| **migrakvota.gov.ru** | Квотный процесс (API неизвестно, возможно ручной ввод) |

## Риски

> По итогам PM-анализа: наличие 30 адаптеров без детальных спецификаций создаёт непредсказуемый объём работ. Требуется приоритизация и поэтапная проработка контрактов.
