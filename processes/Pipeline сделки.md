# Pipeline сделки

## Клиентские этапы (6 + финал)

```mermaid
flowchart LR
  A[Пресейл] --> B[Квоты]
  B --> C[Подбор]
  C --> D[Согласование]
  D --> E[Оформление]
  E --> F[Релокация]
  F --> G[Готов к работе]
```

| # | Этап | Ключевые действующие лица | Что происходит |
|---|------|--------------------------|----------------|
| 1 | **Пресейл** | Админ, Партнёр Индии, Клиент | Назначение партнёров, принятие в работу (Wave 4: формирование КП, согласование условий) |
| 2 | **Квоты** | Партнёр РФ | Подача на квоту (если должность квотируемая) |
| 3 | **Подбор** | Партнёр Индия | Поиск и предложение кандидатов |
| 4 | **Согласование** | Клиент, Партнёр РФ | Клиент одобряет / отклоняет кандидатов |
| 5 | **Оформление** | Партнёр РФ | РНР, виза, приглашение — см. [[Этапы оформления РНР]] |
| 6 | **Релокация** | Партнёр РФ | Въезд, миграционный учёт, чек-лист |
| 7 | **Готов к работе** | Клиент | Специалист приступает к работе |

## Внутренние статусы (11)

`draft` → `new` → `assigned` → `in_work` → `recruitment` → `approval` → `processing` → `relocation` → `completed`

Дополнительно: `paused`, `cancelled` — доступны админу на любом этапе.

## Управление pipeline

- **Пауза / Возобновление** — админ может приостановить сделку с указанием причины; все связанные задачи замораживаются.
- **Отмена** — терминальный статус, возврат невозможен.
- Переход между этапами фиксируется событиями ([[Статусная модель заявки]]).
