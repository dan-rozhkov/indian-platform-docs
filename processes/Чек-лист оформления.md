# Чек-лист оформления

Заполняется после въезда специалиста в РФ. Отслеживается Партнёром РФ.

> [!info] Изменение в ФТ от 9.04 (D15)
> Вместо фиксированного чек-листа из 10 пунктов введена модель **справочника шагов оформления**. Администратор выбирает подмножество шагов для каждой заявки при назначении партнёров (п. 4.4). Каждый шаг: название, признак обязательности, привязка к шаблону документа.

## Справочник шагов оформления (4.3)

Администратор управляет справочником шагов: создание, редактирование, деактивация.

| Параметр шага | Описание |
|---------------|----------|
| Название | Текстовое описание шага (на русском, при необходимости на английском) |
| Обязательность | Да/Нет — влияет на требование выполнения для перевода в «завершён» |
| Шаблон документа | Привязка к шаблону для генерации документа (при наличии) |
| Требует загрузки документа | Да/Нет — некоторые шаги только с отметкой (встреча, SIM-карта), другие требуют документ |

## Типовые шаги чек-листа

Справочник на старте содержит подмножество типовых шагов:

| # | Пункт | Документ | Требует загрузки |
|---|-------|----------|-----------------|
| 1 | Встреча в аэропорту | — | Нет |
| 2 | Медобследование | ✅ | Да (результат) |
| 3 | Дактилоскопия | ✅ | Да (подтверждение) |
| 4 | Регистрация в МВД | ✅ | Да (уведомление) |
| 5 | ИНН | ✅ | Да (свидетельство) |
| 6 | СНИЛС | ✅ | Да (уведомление) |
| 7 | SIM-карта | — | Нет |
| 8 | Зарплатная карта | — | Нет |
| 9 | ДМС / Страховка | ✅ | Да (полис) |
| 10 | Уведомление МВД о трудоустройстве | ✅ | Да (копия уведомления) |

> [!question] Уточнить итоговый перечень шагов справочника (4.1)

## Механика заявки

При назначении партнёров на заявку администратор отмечает галочками, какие шаги из справочника активны для конкретной заявки (4.4, D15). Чек-лист оформления привязан к заявке и содержит только выбранное подмножество.

Каждый пункт чек-листа содержит:
- **Чекбокс** — отметка о выполнении
- **Загрузка документа** — для пунктов, требующих подтверждения (см. [[Загрузка документов]])
- **Комментарий** — свободное текстовое поле
- **Дата** — проставляется автоматически при отметке

Для документов, загружаемых в рамках чек-листа, может использоваться AI-обработка из [[Загрузка документов]]: определение типа документа, раскладка по слотам и сверка данных с профилем кандидата.

## Прогресс-бар

Отображается как **X / N** (где N — количество шагов, выбранных для данной заявки) с визуальной полосой прогресса.

```
████████░░ 8/10
```

## Генерация документов по шаблонам

Для ряда пунктов чек-листа российский партнёр генерирует документы по шаблонам с автоподстановкой данных кандидата (killer feature). Подробнее — [[Документы#Генерация документов по шаблонам]].

Для некоторых документов требуется ввод дополнительных данных:
- **СНИЛС** — адрес места пребывания в РФ (4.12)
- **ИНН** — реквизиты работодателя (4.14)
- **Постановка на учёт МВД** — наименование и адрес органа МВД, адрес пребывания (4.16)

Шаблоны загружаются администратором (4.5).

## SMS-уведомления кандидату

Российский партнёр может отправить кандидату SMS с указанием адреса, даты, времени и перечня документов для явки (4.19).

> [!question] К моменту отправки SMS — кандидат получил российскую SIM-карту? SMS отправляется на российский номер? Кто и когда вводит новый номер? (4.19)

## Финальное оформление

Кнопка **«Передать на финальное оформление»** становится активной только при выполнении всех **обязательных** шагов. До этого кнопка заблокирована.

## Зависимость от пакета услуг

| Пакет | Состав чек-листа |
|-------|-------------------|
| **Стандарт** | Базовые пункты (документы, регистрация) |
| **Премиум** | Все пункты включая SIM, карту, ДМС |
