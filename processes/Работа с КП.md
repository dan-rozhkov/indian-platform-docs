# Работа с КП

Часть этапа **Пресейл** в [[Pipeline сделки]].

## Процесс (ФТ v2)

По функциональным требованиям КП готовит **индийский партнёр**. Клиент напрямую утверждает или отклоняет КП.

```mermaid
sequenceDiagram
  participant India as Партнёр Индии
  participant System as Система
  participant Client as Клиент
  participant Admin as Админ

  India->>Client: Подготавливает и отправляет КП (2.34)
  System->>Client: Уведомление о поступлении КП (2.9)
  Client->>Client: Просматривает КП (2.21)
  alt Утверждает
    Client->>System: Утверждает КП с подтверждением (2.22)
    System->>India: Уведомление об утверждении (2.10)
    India->>India: Начинает подбор кандидатов (2.37)
  else Отклоняет
    Client->>System: Отклоняет КП с указанием причины (2.23)
    System->>Admin: Уведомление об отклонении (2.11)
    Admin->>Admin: Переназначает индийского партнёра (2.31)
    Note over Admin: Новый партнёр готовит КП с чистого листа
  end
```

> [!question] Уточнить процесс: есть ли шаг с КП для всех заявок? (2.1)

## Статусы КП

| Статус | Описание |
|--------|----------|
| **На рассмотрении** | КП отправлено клиенту (2.35) |
| **Утверждено** | Клиент одобрил КП (2.35) |
| **Отклонено** | Клиент отклонил с указанием причины (2.35–2.36) |

## Ключевые правила

- **Индийский партнёр** подготавливает и отправляет КП по заявке клиенту (2.34)
- **Клиент** утверждает или отклоняет КП напрямую (2.22–2.23)
- **Администратор** переназначает партнёра при отклонении КП (2.31)
- Индийский партнёр видит причину отклонения (2.36)
- Данные отстранённого партнёра доступны в режиме «только чтение» (2.32)
