# Организация

Организация — юридическое лицо, зарегистрированное на платформе. Каждый пользователь принадлежит к одной организации и получает [[Роли и суброли|суброль]] в рамках своей роли.

## Типы организаций

| Тип | Описание |
|-----|----------|
| **Клиент** | Российская компания-работодатель, создающая [[Заявка|заявки]] на подбор специалистов |
| **Партнёр РФ** | Российское кадровое агентство, оформляющее [[Документы|документы]] и сопровождающее кандидатов |
| **Партнёр Индии** | Индийское рекрутинговое агентство, осуществляющее подбор [[Кандидат|кандидатов]] и подготовку [[Коммерческое предложение|КП]] |

## Жизненный цикл

```
Создана → Верифицирована ↔ Заблокирована
```

- **Создана** — организация зарегистрирована, ожидает проверки
- **Верифицирована** — администратор подтвердил данные, организация может работать
- **Заблокирована** — доступ приостановлен (можно разблокировать обратно)

В MVP верификация выполняется **вручную** администратором. Автоматическая проверка через внешние реестры запланирована на целевой релиз.

Подробности процесса — [[Регистрация]].

## Пользователи организации

Каждая организация может иметь несколько пользователей с разными субролями. Первый зарегистрированный пользователь получает роль владельца и может приглашать коллег.

## Изоляция данных

Данные строго изолированы между организациями:
- Клиент видит только свои заявки и кандидатов
- Партнёр видит только назначенные ему заказы
- Администратор имеет доступ ко всем организациям

Это обеспечивает конфиденциальность и безопасность данных в мультитенантной архитектуре платформы.
