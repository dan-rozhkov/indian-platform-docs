# Пакеты услуг

Платформа предлагает два пакета услуг, определяющих объём сервиса для [[Заявка|заявки]]. Пакет назначается администратором (менеджером проекта) на этапе квалификации сделки в [[Pipeline сделки]].

## Стандарт

Базовый набор услуг для привлечения [[Кандидат|кандидатов]]:

- Поиск и подбор кандидатов
- Базовая проверка [[Документы|документов]]
- Оформление визы
- Оформление РНР (разрешение на работу)
- Встреча в аэропорту

### Чек-лист оформления (Стандарт)

Определяет обязательные шаги по [[Чек-лист оформления]]:

- [ ] Сбор и проверка документов
- [ ] Медицинское обследование
- [ ] Постановка на миграционный учёт (МВД)
- [ ] Получение ИНН
- [ ] Получение СНИЛС

## Премиум

Расширенный пакет — всё из Стандарта плюс дополнительные услуги:

- ДМС (добровольное медицинское страхование)
- SIM-карта российского оператора
- Зарплатная карта
- Зарплатный проект
- Расширенная логистика (трансфер, размещение)
- Постсопровождение (поддержка после трудоустройства)

### Чек-лист оформления (Премиум)

Все шаги Стандарта плюс:

- [ ] Оформление ДМС
- [ ] Выдача SIM-карты
- [ ] Открытие зарплатной карты
- [ ] Сдача биометрии
- [ ] Продление визы (при необходимости)

## Влияние на процесс

Выбранный пакет определяет:
- Состав [[Чек-лист оформления|чек-листа]] для каждого кандидата
- Набор этапов в [[Pipeline сделки]]
- Стоимость услуг в [[Коммерческое предложение|КП]]
- Объём работы [[Организация|партнёров]]
