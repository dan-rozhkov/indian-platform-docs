# Коммерческое предложение

КП (коммерческое предложение) — документ, подготавливаемый [[Организация|партнёром Индии]] для конкретной [[Заявка|заявки]]. Описывает стоимость услуг, состав работ, сроки и SLA. Является частью пресейл-этапа [[Pipeline сделки]].

## Содержание КП

- Стоимость услуг подбора (за специалиста / за пакет)
- Состав услуг — выбранный [[Пакеты услуг|пакет]] (Стандарт / Премиум)
- Сроки выполнения и SLA
- Условия оплаты
- Дополнительные услуги (при наличии)

## Статусная модель

```
Не загружено → Загружено → На доработке / Передано клиенту
```

- **Не загружено** — КП ещё не подготовлено
- **Загружено** — партнёр Индии загрузил документ
- **На доработке** — администратор вернул на доработку с комментарием
- **Передано клиенту** — администратор одобрил и передал клиенту для ознакомления

## Процесс

1. Партнёр Индии готовит КП на основе данных из [[Бриф|брифа]]
2. Загружает документ в систему
3. Администратор (менеджер проекта) проверяет КП
4. При замечаниях — возвращает на доработку с комментарием
5. При одобрении — передаёт клиенту
6. Клиент знакомится с КП в своём [[Кабинеты|кабинете]]
7. Клиент утверждает или отклоняет КП (2.22–2.23)
8. При отклонении — администратор переназначает партнёра Индии (2.31)

## Версионирование

Система хранит **все версии** КП. При отправке на доработку предыдущая версия сохраняется, партнёр загружает новую. История версий доступна администратору и партнёру Индии.
