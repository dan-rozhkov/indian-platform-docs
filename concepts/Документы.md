# Документы

Документы — сквозная сущность, используемая во всех процессах платформы: регистрации [[Организация|организаций]], оформлении [[Кандидат|кандидатов]] и ведении [[Заявка|заявок]].

## Типы документов

### Корпоративные (организации)
- Устав компании
- ИНН
- ОГРН
- Доверенность на представителя

### Кандидатские
- Загранпаспорт
- Aadhaar (индийский ID)
- Диплом / сертификат квалификации
- Страховой полис
- Результаты медицинского обследования

### Сделочные
- [[Коммерческое предложение|КП]] (коммерческое предложение)
- Договор оказания услуг
- РНР (разрешение на работу)
- РПИРС (разрешение на привлечение иностранной рабочей силы)
- Приглашения на въезд
- Уведомления в МВД

## Статусная модель

### Полная модель (wiki)

```
Не загружен → Загружен → На проверке → Подтверждён / Отклонён
```

- **Не загружен** — документ ожидается, ещё не предоставлен
- **Загружен** — файл загружен, ожидает проверки
- **На проверке** — ответственный проверяет документ
- **Подтверждён** — документ принят
- **Отклонён** — документ отклонён, **обязателен комментарий** с причиной

При отклонении пользователь может загрузить исправленную версию, и цикл повторяется.

### Упрощённая модель (ФТ v2)

Для кандидатских документов используется двухстатусная модель:

```
Ожидает загрузки → Загружен / Сгенерирован
```

Статусы устанавливаются **вручную** российским партнёром (8.2, 5.3).

## Загрузка

- Drag-and-drop из файловой системы
- Поддерживаемые форматы: PDF, JPG, PNG
- Подробнее о UX загрузки — [[Загрузка документов]]

## Проверяющие

Разные типы документов проверяются разными ролями:
- Корпоративные — администратор
- Кандидатские — партнёр РФ / администратор
- Сделочные — администратор / клиент (в зависимости от типа)

## Генерация документов по шаблонам

Российский партнёр генерирует документы по шаблонам с автоподстановкой данных кандидата (killer feature):

| Документ | Доп. данные | Источник |
|----------|------------|----------|
| Разрешение на работу | — | 4.10 |
| Страховой полис | — | 4.11 |
| Заявление на СНИЛС | Адрес места пребывания в РФ | 4.12–4.13 |
| Заявление на ИНН | Реквизиты работодателя | 4.14–4.15 |
| Заявление о постановке на учёт в МВД | Наименование и адрес органа МВД, адрес пребывания | 4.16–4.17 |

Шаблоны документов загружаются администратором (4.5). Сгенерированные документы привязываются к карточке кандидата (4.2) и доступны для скачивания (4.18).

> [!question] Получить примеры документов — ни одного примера пока нет (4.5)

> [!question] Скачивать документы в редактируемом формате (Word/Excel) или только PDF? (4.18)

> [!question] Совпадают ли реквизиты клиента с реквизитами работодателя? Одно и то же это юрлицо или нет? (4.14)

> [!question] Как именно происходит регистрация по месту пребывания приехавшего мигранта? (4.12, 4.16)

## Хранилище и безопасность

- Объектное хранилище файлов: документы, видео кандидатов, вложения к заявкам (8.1)
- Проверка обязательного комплекта документов перед переходом кандидата на следующий статус (8.3)
- Защищённая раздача файлов: скачивание только для авторизованных пользователей с правами доступа (8.4)
