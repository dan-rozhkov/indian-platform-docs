# Бриф

Бриф — структурированная форма, через которую клиент описывает потребность в [[Кандидат|индийских специалистах]]. На основе брифа создаётся [[Заявка]] и запускается [[Pipeline сделки]].

## Структура брифа (4 секции)

### 1. Базовая информация
- Специальность / должность
- Город и регион трудоустройства
- Количество специалистов
- Период привлечения (сроки контракта)
- График работы (сменность)

### 2. Условия работы
- Переработки (наличие, оплата)
- Вредные / опасные условия труда
- Специальные требования (сертификаты, допуски)
- Необходимость переводчика
- Необходимость бригадира (форман)

### 3. Условия для работников
- Транспортировка (трансфер до места работы)
- Проживание (тип, расположение)
- Питание (организация, компенсация)

### 4. Оплата
- Зарплата на испытательном сроке
- Тип расчёта (почасовая / помесячная)
- Зарплата после испытательного срока
- Стоимость питания / проживания (удержание из зарплаты)

## Способы заполнения

- **Форма** — пошаговое заполнение полей в [[Кабинеты|кабинете клиента]]
- **Загрузка файла** — импорт заполненного шаблона (Excel / PDF)
- **Черновики** — автосохранение при заполнении, можно вернуться позже

## Будущие улучшения

В целевом релизе планируется **AI-парсинг**: клиент вводит произвольное текстовое описание потребности, система автоматически извлекает структурированные данные и заполняет поля брифа. Пользователь проверяет и корректирует результат.
