## Детальное описание экранов

### 1. Дашборд

**Тип:** Dashboard
**Приоритет:** MVP

**Ключевые элементы:**
- Счётчики: активные заявки, кандидаты в оформлении, просроченные SLA
- Карточки активных заявок с прогрессом оформления кандидатов
- Визуальный индикатор SLA (светофор) по заявкам
- Быстрые действия: «Начать оформление», «Проверить документы»
- Кандидаты в оформлении с прогрессом чеклистов (12.6, nice to have)

**Требования:** 2.8, 2.14, 2.38, 3.30, 12.6

---

### 2. Список заявок

**Тип:** List
**Приоритет:** MVP

**Ключевые элементы:**
- Таблица заявок: специальность, кол-во, клиент, статус, дедлайн, прогресс оформления
- Фильтрация по статусу и дедлайну
- Поиск по названию/должности
- Кнопка «Взял в работу» (появляется при новом назначении, 3.30)
- Индикатор оставшегося времени по SLA (2.38)
- SLA на принятие заявки в работу (2.14, 2.29)

**Требования:** 2.8, 2.14, 2.29, 2.38, 3.30

---

### 3. Детальная заявка

**Тип:** Detail
**Приоритет:** MVP

**Ключевые элементы:**
- Параметры заявки: специальность, количество, требования, дедлайн
- Информация о клиенте
- Список одобренных кандидатов для оформления
- Прогресс-бар оформления (N из M кандидатов оформлено)
- Визуализация SLA
- Переход в карточку кандидата

**Требования:** 2.38, 4.6

---

### 4. Карточка кандидата

**Тип:** Detail (с вкладками)
**Приоритет:** MVP

**Ключевые элементы:**
- **Вкладка «Данные кандидата»** — анкетные данные (4.8)
- **Вкладка «Документы»** — список загруженных документов со статусами (4.9)
- **Вкладка «Чеклист»** — чеклист оформления с ручными отметками выполненных шагов (4.7, killer feature). По умолчанию: медосмотр, постановка на учёт в МВД, СНИЛС, ИНН, страховка, SIM-карта, разрешение на работу (4.1)
- **Вкладка «Чат»** — чат с кандидатом с GigaChat-переводом (3.31, killer feature)

**Требования:** 3.31, 4.1, 4.6, 4.7, 4.8, 4.9

---

### 5. Генерация документов

**Тип:** Tool
**Приоритет:** MVP

**Ключевые элементы:**
- Генерация разрешения на работу по шаблону с подстановкой данных кандидата (4.10, killer feature)
- Генерация страхового полиса по шаблону (4.11, killer feature)
- Генерация заявления на СНИЛС (4.13, killer feature) — требует адрес места пребывания (4.12)
- Генерация заявления на ИНН (4.15, killer feature) — требует реквизиты работодателя (4.14)
- Генерация заявления о постановке на учёт в МВД (4.17, killer feature) — требует наименование/адрес МВД, адрес пребывания (4.16)
- Скачивание сгенерированного документа (4.18)
- Отправка SMS-уведомления кандидату о необходимости явиться: адрес, дата, время, перечень документов (4.19)

**Требования:** 4.10, 4.11, 4.12, 4.13, 4.14, 4.15, 4.16, 4.17, 4.18, 4.19

## Замечания

- Все MVP экраны (1–5) реализованы в прототипе
- Экран 4 (Карточка кандидата) — ключевой экран с 4 вкладками, включает killer feature: чеклист оформления и чат с GigaChat-переводом
- Экран 5 (Генерация документов) — основной killer feature кабинета: генерация 5 типов документов по шаблонам с подстановкой данных кандидата
- Партнёр РФ работает с кандидатами **после** одобрения клиентом — он не подбирает, а оформляет
- Экран 6 (Логистика) — назначен на отдельную суброль «Логист», не входит в MVP
- Экран 7 (Продление визы) — целевой контур, не входит в MVP
- Экран 8 (Настройки профиля) — nice to have, не входит в MVP
- Открытый фича-реквест: массовый прочек по чеклисту для групп кандидатов (от 7.04)
- Статус актуализирован на основе `raw/prototype.md` от 9.04
